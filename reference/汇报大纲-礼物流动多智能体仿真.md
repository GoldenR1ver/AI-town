# 礼物流动 · 多智能体社会学仿真实验汇报大纲

> **汇报主线**：用阎云翔式「礼物闭环」证明——多智能体对人类行为的拟真**可以落到可检验指标**；各组件（规则引擎 / BDIE / **认知树** / 礼单账本 / LLM 话语）**分工明确、作用不可互相替代**；因此用多智能体拟真人类社会**有方法论可取之处**。  
> 科学性四维仍对齐 `reference/多智能体社会学仿真实验方法总结.md`（效度 / 机制 / 可证伪性 / 伦理）。  
> 建议总时长：**15–20 分钟讲解 + 5 分钟可视化演示**。

---

## 0. 开场：为什么用多智能体拟真社会？（1.5 min）

| 要点 | 内容提示 |
|------|----------|
| 一句话问题 | 在村庄社会网络中，**互惠规范、地位分层与回礼义务**如何共同塑造礼物流动与面子/声望分布？ |
| 方法主张（今日论点） | 不是「让 LLM 聊天看起来像人」，而是：**显式社会规则 + 个体认知状态 + 主观记忆 + 可选话语** 的混合多智能体，可复现民族志式宏观中态，并保留可拆解的微观机制。 |
| 理论锚点 | 阎云翔《礼物的流动》——欠情—还情的时间性、人情道德性、纵向/横向互惠不对称 |
| 今日交付 | **为何可取** → **组件如何各司其职** → **拟真证据** → 可视化 → 局限与下一步 |

**开场话术建议**：

> 「社会学关心的是规范如何在互动中涌现。纯统计拟合缺过程；纯 LLM 对话缺可证伪的规则承诺。我们用多智能体把**人情规则写进世界**，把**个体状态写进 Agent**，再用实验问：这样拟真出来的村落，像不像真实人情社会？」

## 1. 研究问题、假说与「拟真成功」判据（2.5 min）

### 1.1 研究问题（RQ）

1. **RQ1（宏观涌现）**：长期运行后，礼物流是否向高声望节点集中？互惠率与违约率是否处于「多数偿还、少量违约、非即时对等」的中态？
2. **RQ2（机制可拆解）**：回礼窗口、关系轴、经济约束、认知驱动是否各自解释得通个体面子稳定/崩塌？
3. **RQ3（过程像人）**：回礼是否延迟互惠？决策/话语是否与压力、欠情、讨厌一致？
4. **RQ4（方法价值）**：相对「单一黑箱模型」，多智能体组件消融后，社会指标是否系统性变差——从而证明各组件**独特贡献**？

### 1.2 可检验假说

| 假说 | 预期可观测指标 | 证伪方式 |
|------|----------------|----------|
| H1 声望吸引 | `gift_prestige_corr > 0`，Top10 声望礼份额显著 | 相关≈0 或财富相关更强 |
| H2 互惠中态 | reciprocity ≈ 0.7–0.95；default ≈ 0.05–0.25（短跑可放宽至 0.02–0.20） | 全员即时还清或大规模违约 |
| H3 纵向不对称 | 弱关系→高地位「进贡式」礼不进一对一债窗 | 干部因收礼过多系统性 face→0 |
| H4 延迟互惠 | `avg_repay_delay` 显著 > 0（跨若干 slot） | 几乎全部同 slot 回礼 |
| H5 状态—行为一致 | 高压少主动请客；欠情临窗优先还礼；讨厌驱动闲话 | 话语/决策与情绪、礼债系统性背离 |

### 1.3 「符合真实情况」怎么讲（避免空泛）

汇报时把「真实」操作化为**三重对齐**，而不是「感觉像」：

| 对齐层 | 对标什么 | 本实验证据入口 |
|--------|----------|----------------|
| **民族志模式对齐** | 阎云翔：延迟还情、分层收礼、少量违约 | live100 宏观表（§5） |
| **过程机制对齐** | 欠情—还情时间性（W4/W5/W10）、喜事难拒 | 规则 + 短跑对齐验收（§5.2） |
| **状态—话语对齐** | 高压/内向/讨厌时说话不像热心东道主 | `analyze:discourse`（§5.2） |

> **汇报话术**：宏观像村落 ≠ 微观等于真人；我们声称的是——**关键社会过程的可检验相似性**，并为理论筛选提供可回放证据。

## 2. 为何多智能体「有可取之处」（2 min）——方法论立场

对听众可能有的质疑，提前给答案：

| 质疑 | 回应（可取之处） |
|------|------------------|
| 「直接用一个大模型扮演全村不行吗？」 | 单一黑箱难做**组件因果**；无法回答「关掉认知树 / 关掉互惠规则」后社会指标如何变。 |
| 「规则写死还算仿真吗？」 | 人情本就有**可陈述规范**（回礼窗口、场合、纵向不对称）；规则负责**承诺与结算**，LLM 负责**语义表达**——内容与决策分离（方法总结 3A）。 |
| 「宏观像就够了？」 | 不够。我们补**过程层**（延迟、Intention、对话快照）与**消融**，防止「假拟真」。 |
| 「有什么科学产出？」 | （1）假说筛选；（2）病理发现与修复（如主任脸面归零）；（3）可复现实验资产（seed、日志、回放）。 |

**一句话收束**：多智能体拟真的可取之处在于——把「社会」拆成**可开关、可计量、可回放**的机制单元，而不是一次性生成一段像人的故事。

## 3. 系统组件：合理分工与独特作用（4 min）★核心页

### 3.1 架构一张图（口述）

```
事件生成（目录/社交驱动/回礼驱动）
    → [可选] LLM 对话（语义；受状态叙事约束）
    → PET 更新 + 认知树归档
    → BDIE（信念/欲望/意图/情绪）驱动偏好与拒绝
    → 送礼/回礼提案
    → RuleEngine 唯一写世界（经济、关系、面子、礼单）
    → giftWindowCheck / W4–W10 时间性
```

### 3.2 组件「独特作用」对照表（建议做一页幻灯）

| 组件 | 模拟人类的哪一块 | 为何不能被别的模块替代 | 关掉会怎样（直觉） |
|------|------------------|------------------------|--------------------|
| **RuleEngine + 礼单账本** | 人情**规范与结算**（送/还/违约/场合） | LLM 不能「声称已改现金」；规则保证世界一致性 | 互惠崩溃或账目不可信 |
| **关系图（轴/亲缘/讨厌）** | 社会结构与情感取向 | 决定纵向不对称、闲话对象、拒绝对象 | H3 失效；闲话无靶 |
| **BDIE（情绪/意图）** | 当下身心状态与行动优先级 | 把「手头紧/高压/欠情临窗」变成可计算驱动 | 社交与回礼变「平均人」 |
| **认知树** | **主观记忆与关系叙事**（谁对谁说过什么、上呈摘要） | 不是客观真理边，而是「我认为我们的关系是…」；支撑后续对话与面子感知 | 对话失语境；关系史无法主观累积（消融 A2） |
| **PET（个人事件表）** | 近期显著事件记忆 | 比全局日志更贴近「个人记得什么」 | 事件提及与针对性回应变弱 |
| **LLM 对话** | 自然语言表达与局部态度 | 规则不会「说话」；话语是过程证据 | 只剩指标，缺可演示的微观互动 |
| **日活力 / 经济** | 生存约束与压力底噪 | 无经济则礼俗变成无限请客游戏（消融 A3） | 礼期望膨胀、分层扭曲 |

### 3.3 认知树：单独讲 30–40 秒（容易被问）

**定位**：认知树不是第二套关系数据库，而是 Agent 的**主观关系记忆结构**（dialogue → relation/circle 上呈）。

**独特价值三点**：

1. **主客分离**：世界边是「客观可结算关系」；认知树是「我以为的关系史」——符合社会学「定义情境」传统。  
2. **时间累积**：对话摘要可晋升节点，支撑长期互动而非每轮失忆。  
3. **可消融验证**：A2 关闭认知树，可检验主观记忆对社会指标/对话质量的贡献（方法总结要求的组件因果）。

**汇报话术**：

> 「如果只有关系边上的信任分数，Agent 知道『亲密度=60』，但不知道『上周在婚礼上我帮过他』。认知树补的是这种**可叙述的主观历史**。」

### 3.4 内容与决策分离（强调合理性）

| 模块 | 谁决定 | 可解释性 |
|------|--------|----------|
| 是否送礼 / 对象偏好 | 规则 + BDIE + 关系图 + 礼债紧迫度 | 高 |
| 对话话语 | LLM（受个人状态叙事 / 欠情约束） | 中（日志可回放） |
| 回礼是否尝试 | 概率模型（经济×关系×身份×窗口） | 高 |
| 是否违约、惩罚幅度 | RuleEngine + severity（含困难减免） | 高 |

## 4. 实验设计与效度（2 min）

### 4.1 效度要点

- **理论操作化**：表达性/工具性、回礼窗口、违约严重度、跨场合抵扣 → `rule-of-return-gift.md`
- **条件化 Agent**：职业、收入、BigFive、性格派生（内向/挑剔/记仇）、社会标签、关系轴
- **人类经验基准**：阎云翔民族志模式 + 短跑「理想带」验收（非严格问卷硅基采样；局限中声明）
- **规模梯度**：16 人机制 Demo → **100×30 mock 对齐标定** → **100×365 Live LLM** 主结果

### 4.2 可证伪与消融（已具备）

- A0 全开 vs A1 无 BDIE vs **A2 无认知树** vs A3 无限资金  
- E1 礼单记忆 / E2 互惠规则 / E3 纵向关系 / E4 场合规范  
- 三层指标：宏观 metrics · 微观个体 · 过程（delay / Intention / 话语）

### 4.3 伦理与对齐声明（一句话）

宏观「像村落互惠」≠ 微观认知完全像人；本系统用于**机制探索、假说筛选与教学演示**，不替代田野。

## 5. 拟真证据：主结果 + 对齐短跑（5 min）★

### 5.1 主跑次（民族志模式对齐）

> Run：`live100_365d_20260725_1643`  
> 100 Agents · 365 天 · baseline · DeepSeek · seed=42

| 指标 | 结果 | 对「像真实人情」的解读 |
|------|------|------------------------|
| reciprocity_rate | **0.90** | 多数还情，符合互惠中态（H2） |
| default_rate | **0.022** | 有违约但不崩溃 |
| avg_repay_delay | **~17 slots** | 延迟互惠，非即时会计（H4） |
| gift_prestige_corr | **0.51** | 声望吸引礼物流（H1） |
| gift_wealth_corr | **0.07** | 不是有钱就多收（非纯经济） |
| Top10 声望礼份额 | **27%** | 中度集中，像分层村庄 |
| prestige_gini | **0.16** | 有分层、不极端 |
| dialogues | **344**（0 fail） | Live 话语真正接入过程 |

**微观点名（支持 H3）**：

- 高地位（主任/退休干部）：收礼多、defaults≈0、face 维持 → 进贡不毁脸  
- 对照早期病理：主任 face→0 经准纵向/窗口/容量回礼修复后消失 → **说明组件设计在纠正「不像人」的失败模式**

### 5.2 对齐短跑（过程与状态一致性）

> Run：`tune_align_v2_100_30d`（mock · 100×30）· 验收 **12/12**

| 维度 | 结果 | 意义 |
|------|------|------|
| 情绪带 | mood≈0.55，stress≈0.27，energy≈0.87 | 非全员崩溃、非无压力乌托邦 |
| 互惠/违约 | reciprocity≈0.86，default≈0.025 | 短视界仍落在理想带 |
| 拒绝 | ~1.3 次/天 | 有推脱，非无脑参与 |
| 闲话/讨厌 | gossip 活跃，dislike≥35 边存在 | 情感负向可累积 |
| 话语对齐 | alignmentRate≈1.0，warn=0 | 高压话语未系统性「请客做东」 |
| 决策对齐 | 喜事难拒、欠情临窗优先还礼、Prompt 注入「欠情未还」 | 说与做同一套约束 |
| 时间性 | W4 跨场合还礼日志可查；窗口/延期规则落地 | 人情≠银行即时清算 |

### 5.3 汇报时的「证据链」说法

1. **宏观像**：声望集中 + 延迟互惠中态（live100）  
2. **机制通**：关掉/打开规则与认知组件可做消融（A/E）  
3. **微观不离谱**：对齐短跑通过情绪/拒绝/话语/礼债一致性检查  
4. **失败可修**：早期 face 归零被机制修补 → 拟真是迭代逼近，而非一次生成

## 7. 消融：证明「组件独特」（2 min）

只报 1–2 组，每组一句理论方向：

| 消融 | 预期（若组件真有用） |
|------|----------------------|
| **A2 无认知树** | 对话语境与主观关系史变弱；长期互动质量下降 |
| A1 无 BDIE | 社交发起/拒绝/回礼紧迫度「变平」 |
| A3 无限资金 | 礼期望膨胀，经济约束假说被破坏 |
| E2 互惠规则关 | 违约↑、互惠↓ |

**话术**：消融不是凑材料，而是回答——「多智能体多出来的那些模块，是不是真的在干活？」

## 8. 局限（1 min，坦诚反而加分）

1. **宏观-微观解离风险**：群体指标像民族志，不证明每个 Agent 的神经/心理过程像人  
2. **人类数据对齐仍浅**：尚未做问卷边际 / 分布级 KS 对照（方法总结 2A/2D）  
3. **时序简化**：同步 slot ≠ 真实 burstiness；话语由 LLM、时机由时钟/概率  
4. **模型敏感性**：主结果单一 live 模型；短跑对齐多为 mock  
5. **伦理边界**：机制探索与教学，不替代田野因果识别  

---

## 9. 结论：三个「可取之处」（1 min）

### 9.1 结论三句（建议背下来）

1. **拟真可检验**：在混合架构下，100 人村庄复现了声望吸引的礼物集中与延迟互惠中态，并与短跑对齐带一致。  
2. **组件有独特作用**：规则负责规范承诺，BDIE 负责状态驱动，**认知树负责主观关系记忆**，LLM 负责可回放话语——彼此不可替代，可用消融追问。  
3. **方法可取**：多智能体社会拟真的价值，在于把人情社会变成**可开关机制 + 三层指标 + 可回放过程**的实验装置，服务于理论筛选与教学演示，而非替代真人田野。
