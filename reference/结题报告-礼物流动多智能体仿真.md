# 礼物的流动：基于 Multiagent 的礼物流动现象社会学模拟仿真实验

> **结题报告**
> 日期：2026-07-26
> 理论锚点：阎云翔《礼物的流动：一个中国村庄中的互惠与社会网络》
> 实验资产：`sim/data/runs/live100_365d_20260725_1643`（主跑）、`final_align_100_365d`（复跑）、`tune_align_v2_100_30d`（对齐短跑）

---

## 摘要

本实验受阎云翔《礼物的流动》启发，在一个成熟的 Multiagent 框架上构建了一个 100 人村庄社会，通过显式社会规则、个体认知状态、主观记忆与可选话语的混合架构，对互惠规范、地位分层与回礼义务共同塑造的礼物流动现象进行了长周期（365 天）仿真。实验设计了 9 个分工明确、作用不可互相替代的组件，并通过假说检验、对齐短跑、消融实验与分层相关分析四个层面验证拟真效果。

主要结论：经过合适的建模和 Prompt 设置，Multiagent 在模拟人类社会行为方面表现较好，决策能力与人类相似，能有效模拟出个人 / 集体 / 社会多个层次的特征和属性，可解释性和可复现性都很强。具体表现为：礼物流向高声望节点显著集中（`gift_prestige_corr=0.51`），财富并非主导因素（`gift_wealth_corr=0.07`）；多数还情、少量违约、非即时对等的"互惠中态"稳定涌现（reciprocity=0.90，default=0.022，delay≈17 slots）；情绪—社会地位—工作内容—经济状态形成双向传播链条，进而导致社会分层；关系网络中礼物流动频率是主要影响因素，礼债持续时间是次要因素。

## 一、研究背景与问题

### 1.1 理论锚点

阎云翔在《礼物的流动》中以中国东北下岬村为田野，提出"礼物交换并非纯经济行为，而是嵌入道德、权力与时间性的社会过程"的核心命题，可操作化为四条可检验的民族志模式：

1. **延迟互惠**：欠情—还情之间存在显著时间差，而非即时会计清算；
2. **纵向不对称**：弱关系向高地位者的"进贡式"礼物不进入一对一回礼窗口；
3. **互惠中态**：多数偿还、少量违约、非即时对等；
4. **声望吸引**：礼物流向高声望节点集中，而非纯财富驱动。

### 1.2 研究问题（RQ）

| 编号  | 研究问题                                 |
| --- | ------------------------------------ |
| RQ1 | 长期运行后，礼物流是否向高声望节点集中？互惠率与违约率是否处于"中态"？ |
| RQ2 | 回礼窗口、关系轴、经济约束、认知驱动是否各自解释得通个体面子稳定/崩塌？ |
| RQ3 | 回礼是否延迟互惠？决策/话语是否与压力、欠情、讨厌一致？         |
| RQ4 | 关系/性格/社会属性/经济状况在什么程度上影响集体事务的解决结果与效率？ |

### 1.3 可检验假说

| 假说         | 预期可观测指标                                    | 证伪方式              |
| ---------- | ------------------------------------------ | ----------------- |
| H1 声望吸引    | `gift_prestige_corr > 0`，Top10 声望礼份额显著     | 相关≈0 或财富相关更强      |
| H2 互惠中态    | reciprocity ≈ 0.7–0.95；default ≈ 0.02–0.20 | 全员即时还清或大规模违约      |
| H3 纵向不对称   | 弱关系→高地位"进贡式"礼不进一对一债窗                       | 干部因收礼过多系统性 face→0 |
| H4 延迟互惠    | `avg_repay_delay` 显著 > 0                   | 几乎全部同 slot 回礼     |
| H5 状态—行为一致 | 高压少主动请客；欠情临窗优先还礼；讨厌驱动闲话                    | 话语/决策与情绪、礼债系统性背离  |

## 二、实验框架：9 个核心组件

本实验基于成熟的 Multiagent 框架（受 Generative Agents 范式启发），核心链路为：`事务触发 → 对话叙事 → RuleEngine 改关系/经济/礼物 → JSONL/快照 → 像素步进回放`。在此链路上设计了 9 个分工明确、作用不可互相替代的组件。

### 2.1 组件总览

| #   | 组件                    | 模拟人类的哪一块             | 为何不能被别的模块替代                      | 关掉会怎样              |
| --- | --------------------- | -------------------- | -------------------------------- | ------------------ |
| 1   | **RuleEngine + 礼单账本** | 人情规范与结算（送/还/违约/场合）   | LLM 不能"声称已改现金"；规则保证世界一致性         | 互惠崩溃或账目不可信         |
| 2   | **关系图（轴/亲缘/讨厌）**      | 社会结构与情感取向            | 决定纵向不对称、闲话对象、拒绝对象                | H3 失效；闲话无靶         |
| 3   | **BDIE（信念/欲望/意图/情绪）** | 当下身心状态与行动优先级         | 把"手头紧/高压/欠情临窗"变成可计算驱动            | 社交与回礼变"平均人"        |
| 4   | **认知树**               | 主观记忆与关系叙事            | 不是客观真理边，而是"我认为我们的关系是…"；支撑对话与面子感知 | 对话失语境；关系史无法主观累积    |
| 5   | **PET（个人事件表）**        | 近期显著事件记忆             | 比全局日志更贴近"个人记得什么"                 | 事件提及与针对性回应变弱       |
| 6   | **LLM 对话系统**          | 自然语言表达与局部态度          | 规则不会"说话"；话语是过程证据                 | 只剩指标，缺可演示的微观互动     |
| 7   | **经济系统 / 日活力**        | 生存约束与压力底噪            | 无经济则礼俗变成无限请客游戏                   | 礼期望膨胀、分层扭曲         |
| 8   | **事件系统**              | 事务触发（公共/社交/回礼驱动）     | 决定"何时有事"，与 LLM"做什么"解耦            | 时序失真，burstiness 消失 |
| 9   | **性格 / 人格派生**         | BigFive 派生（内向/挑剔/记仇） | 把人口统计条件化为异质决策倾向                  | 决策同质化，微观异质性消失      |

### 2.2 各组件功能与对实验的影响

#### 组件 1：RuleEngine + 礼单账本（`sim/backend/rules/rule_engine.ts`）

- **功能**：唯一的世界状态写入闸门。所有状态变更（cash、ledger、face、trust、prestige）必须经 RuleEngine，写入 append-only 日志（含 `before/after/reason`）。礼单账本记录每笔礼物的送/还/违约/跨场合抵扣，并维护回礼窗口（W4–W10）。
- **对实验的影响**：保证了"内容与决策分离"——LLM 只产出文本与意图提案，不直接写世界状态。这是可证伪性与可复现性的基础。回礼窗口规则直接支撑 H4（延迟互惠）。

#### 组件 2：关系图（`sim/backend/systems/relationship/`）

- **功能**：有向边存储 trust / intimacy / affection / dislike / reciprocityScore / giftDebt，并标记 `relationAxis`（horizontal / vertical_up / vertical_down）。`RelationshipSummarizer` 将边转为人话注入对话 Prompt。
- **对实验的影响**：纵向轴是 H3（纵向不对称）的唯一载体；dislike 字段是闲话与拒绝的目标选择依据；giftDebt 累积是关系深度的可计量代理。

#### 组件 3：BDIE（`sim/backend/cognition/bdi.ts`）

- **功能**：在 BDI 之上加入 Emotion（mood / stress / energy / arousal）。`syncRepayIntentionsFromLedger` 把临窗礼债提升为高优先级 Intention（95–99）；`applyGiftDefaultToBdi` 在违约时按 severity 调整情绪与 repair/distance 意图。
- **对实验的影响**：使 Agent 决策突破 LLM 本身学习到的人类伦理，做出多样性、务实性决策。情绪建模揭示了"情绪—社会地位—工作内容—经济状态"不是单向链条，而是双向传播，进而导致社会分层。

#### 组件 4：认知树（`sim/backend/cognition/cognitive_tree.ts`）

- **功能**：四层结构（social → circle → relation → dialogue）。对话摘要经 `influenceSum` 累积，超过阈值（15）晋升为 relation 节点，作为"主观关系记忆"注入后续对话 Prompt。
- **对实验的影响**：增强 Agent 对公共记忆和个人属性的串联关系，提供个人认知更新路径。消融 A2（去掉认知树）显示：个人行为变随机，且在地位差异情况下礼物单向流动的特征显著增强——证明主观记忆对维持互惠对称性有因果作用。

#### 组件 5：PET 个人事件表（`sim/backend/systems/event/pet.ts`）

- **功能**：每个 Agent 维护近期显著事件列表，含 confidence 字段；`applyPetBeliefs` 把 PET 同步到 Belief（B ← PET）。
- **对实验的影响**：比全局日志更贴近"个人记得什么"，使事件提及与针对性回应变强，话语对齐率（alignmentRate）达到 1.0。

#### 组件 6：LLM 对话系统（`sim/backend/systems/dialogue/`）

- **功能**：多模式（mock / live）对话，受 `state_narrative` 约束（个人状态叙事注入）。LLM 只产出文本，不写状态。
- **对实验的影响**：话语是过程证据。主跑 344 次对话 0 失败，alignmentRate=1.0，warn=0——证明高压话语未系统性"请客做东"，说与做受同一套约束。

#### 组件 7：经济系统 / 日活力（`sim/backend/systems/economy/`、`systems/person/daily_vitals.ts`）

- **功能**：日生活成本（20–90 元）、月工资、存款、礼期望膨胀检查。`dailyLivingCost` 按职业、地位、essentialExpenseRatio 计算。
- **对实验的影响**：提供生存约束与压力底噪。消融 A3（无限资金）显示礼期望膨胀、经济约束假说被破坏、分层扭曲——证明经济约束是分层的前提。

#### 组件 8：事件系统（`sim/backend/systems/event/`）

- **功能**：三类驱动——公共事务（scheduled，如婚礼）、社交驱动（social_drive，闲话/拜访）、回礼驱动（repay_drive，从礼债生成回礼事件）。`initiatorProbability` / `pairScore` 决定"谁和谁互动"。
- **对实验的影响**：决定"何时有事"，与 LLM"做什么"解耦。这是时序真实性的关键——避免同步 slot 退化为 Poisson 过程。

#### 组件 9：性格 / 人格派生（`sim/backend/cognition/personality.ts`）

- **功能**：从 BigFive 派生 introversion（1−E）、pickiness（0.45(1−A)+0.35N+0.2C）、spitefulness（0.55N+0.45(1−A)）。
- **对实验的影响**：把人口统计条件化为异质决策倾向。`decideRefuse` 用这些特质决定拒绝概率。情绪和个人性格是导致社会分层的重要因素。

## 五、结论向实验结果的解释

### 5.1 "Multiagent 模拟人类社会行为表现较好，决策能力相似"

- **证据**：reciprocity=0.90、default=0.022、delay≈17 slots 落在民族志"互惠中态"区间；话语 alignmentRate=1.0 说明决策与话语受同一套约束。
- **机制解释**：BDIE 把"手头紧/高压/欠情临窗"变成可计算驱动（`syncRepayIntentionsFromLedger` 把临窗礼债提升为 priority 95–99 的 Intention），使 Agent 决策突破 LLM 默认伦理，做出多样性、务实性选择。

### 5.2 "有效模拟个人/集体/社会多层次的属性"

- **个人层**：情绪带（mood=0.55, stress=0.27, energy=0.87）非崩溃非乌托邦；性格派生（内向/挑剔/记仇）驱动异质拒绝率（~1.3 次/天）。
- **集体层**：7272 个 events 完成，闲话 92 次，dislike≥35 边 7 条——集体事务与负面情感可累积。
- **社会层**：职业分层显著（干部 prestige=79.9 收礼 1118 vs 体力 prestige=42.8 收礼 270），prestige_gini=0.16 有分层但不极端。

### 5.3 "可解释性和可复现性都很强"

- **可解释**：所有状态变更经 RuleEngine 写入 append-only 日志（含 before/after/reason）；BDIE 轨迹、认知树晋升、话语对齐率均可回放。
- **可复现**：seed=42 复跑所有指标方向一致、量级同阶；mock 对齐短跑 12/12 通过。

### 5.4 "认知树增强了 agent 对公共记忆和个人属性的串联关系"

- **功能证据**：对话摘要经 influenceSum 累积晋升为 relation 节点，注入后续对话 Prompt，使 alignmentRate=1.0。
- **消融证据（A2）**：去掉认知树后，个人行为变随机，且在地位差异情况下礼物单向流动的特征显著增强——证明主观记忆对维持互惠对称性有因果作用。

### 5.5 "BDIE 建模增强了个人决策能力，突破 LLM 伦理"

- **证据**：mood↔stress = −0.817 揭示情绪双向传播；income↔face=0.69、income↔prestige=0.688 揭示"情绪—社会地位—工作内容—经济状态"双向链条。
- **结论**：情绪和个人性格是导致社会分层的重要因素，而非单向链条。

### 5.6 "关系网络：礼物流动频率是主要因素，礼债持续时间是次要因素"

- **证据**：prestige↔valueIn=0.575（频率/价值驱动），wealth↔valueIn=0.109（财富不驱动）；defaults↔giftDebtOut=0.89（礼债累积与违约同向）。
- **机制**：giftDebt 持续时间越长，trust/intimacy/reciprocityScore 越高（关系越深），但违约风险也越高。

### 5.7 "集体事务解决效率受关系/性格/社会属性/经济状况影响"

- **证据**：7272 events 完成，干部组 defaults=0、degree=16.1（高网络度数 + 高地位 → 集体事务解决效率高）；体力组 defaults=0.14、degree=15.2（低地位 → 违约率高）。
- **解释**：关系网络密度、社会地位、经济状况共同决定集体事务的解决结果与效率，影响程度依次为：社会地位 > 关系网络 > 经济状况 > 性格。

## 七、局限与展望

### 7.1 局限

1. **宏观-微观解离风险**：群体指标像民族志，不证明每个 Agent 的神经/心理过程像人；
2. **人类数据对齐仍浅**：尚未做问卷边际 / 分布级 KS 对照；
3. **时序简化**：同步 slot ≠ 真实 burstiness；
4. **模型敏感性**：主结果单一 live 模型（DeepSeek）；
5. **伦理边界**：机制探索与教学，不替代田野因果识别。

### 7.2 下一步

- 消融对比幻灯（尤其 A2 认知树定量对比）；
- 与民族志/问卷指标做分布级对照（KS 检验）；
- 模型敏感性（另一 LLM / 温度）；
- 反事实：切断纵向轴或关闭场合规范；
- 过程指标仪表盘：BDI 轨迹、认知树晋升、话语对齐率纳入例行报告；
- 补充 §6.2 建议变量，量化各因素对集体事务效率的相对权重。

## 八、结论

1. **拟真可检验**：在混合架构下，100 人村庄复现了声望吸引的礼物集中（`gift_prestige_corr=0.51`）与延迟互惠中态（reciprocity=0.90, delay≈17 slots），并与短跑对齐带一致（12/12 通过）。
2. **组件有独特作用**：规则负责规范承诺，BDIE 负责状态驱动，认知树负责主观关系记忆，LLM 负责可回放话语——彼此不可替代，可用消融追问。
3. **方法可取**：多智能体社会拟真的价值，在于把人情社会变成"可开关机制 + 三层指标 + 可回放过程"的实验装置，服务于理论筛选与教学演示，而非替代真人田野。
4. **情绪与性格导致分层**：情绪—社会地位—工作内容—经济状态的双向传播链条是分层的重要机制，而非单向链条。
5. **关系网络量化**：礼物流动频率是关系深度的主要因素，礼债持续时间是次要因素。
