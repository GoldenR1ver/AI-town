# Frontend (D2+)

Read-only replay UI. Do **not** couple to a game engine.

```
replay/
  index.html      # timeline shell
  app.js
  styles.css
  demo_data.json  # generated by npm run frontend:export
serve.ts          # static server on :5177
```

```bash
npm run sim:seed-gifts
npm run frontend:export
npm run frontend:serve
# open http://127.0.0.1:5177/
```
